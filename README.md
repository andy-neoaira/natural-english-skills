# 中译英自然写作技能集

两个通用的 Agent Skill，用于把中文内容改写成**英语母语者会直接写出的英文**，避免逐字翻译、翻译腔和模板化 AI 文风。

目标不是"把中文翻译成英文"，而是"像作者本来就用英语写作"：自然表达优先于字面对齐，意思忠实优先于文案效果。

## 技能

### write-natural-english-reply —— 回复类

针对**已有英文原帖**（X/Twitter、Reddit、论坛、评论区、社群、普通聊天），把中文回复意图改写为贴合原帖语境的自然英文回复。

- 输入：英文原帖 + 中文回复意图
- 输出：英文回复 + 中文回译 + 母语者视角审查
- 适用：`翻译成适合回复的英语`、`更口语化`、`不要翻译腔`、`根据上下文写英文回复` 等场景

### write-natural-english-post —— 发帖类

把**中文帖子或发帖想法**改写为自然、可直接发布的英文原创帖，保留作者的观点、细节和个人语气。

- 输入：中文帖子或中文发帖想法（无需英文原帖）
- 输出：英文帖子 + 中文回译 + 英语读者视角审查
- 适用：`把这段话写成英文帖`、`翻译成英文发到 X`、`用英语表达这个观点` 等场景

## 如何选择

| 场景 | 技能 |
|------|------|
| 有英文原帖，要回复它 | `write-natural-english-reply` |
| 只是发帖 / 表达观点，没有原帖 | `write-natural-english-post` |

## 格式与安装

两个技能都遵循通用的 Agent Skill 约定：

- 每个技能是一个独立目录，目录名即技能名；
- 目录内包含一个 `SKILL.md`，文件开头是 YAML frontmatter，提供 `name` 和 `description`；
- `description` 用于让 Agent 判断何时加载该技能。

安装时，把技能目录放进你所使用 Agent 约定的技能目录即可。常见位置：

```
~/.agents/skills/<skill-name>/SKILL.md      # 用户级
<project>/.agents/skills/<skill-name>/SKILL.md   # 项目级
```

目录名需与 `SKILL.md` 中的 `name` 保持一致。不同 Agent 的技能目录和加载规则可能略有差异，以其文档为准。

## 目录结构

```
.
├── README.md
├── write-natural-english-reply/
│   └── SKILL.md
└── write-natural-english-post/
    └── SKILL.md
```

## 共同设计原则

- **自然优先**：按英语的信息顺序重新写作，不保留中文句式。
- **忠实作者**：保留第一人称、情绪分寸和不确定程度，不擅自增加经历、数据、事实或立场。
- **回译 + 审查**：生成英文后回译成中文，并从母语者视角检查自然度和翻译/AI 痕迹；发现问题先改英文，不展示未通过的草稿。
- **消除翻译腔 / AI 腔**：以可观察的表达特征为准（中文语序、三段式排比、无意义铺垫、对称转折等），不把单个单词或标点当作 AI 证据，也不承诺"通过检测器"。
- **可降级输出**：默认给完整三段式（英文 / 回译 / 视角分析）；用户明确要求"只要英文"时，只输出最终英文成稿。
